# Clark Regional Emergency Services Repository

Welcome to the **Clark Regional Emergency Services Repository** – a working collection of documents, scripts, and other resources developed to support the operations, planning, and technology needs of the Clark Regional Emergency Services Agency (CRESA).

## 📁 Repository Purpose

This repository serves as a centralized location for:
- PowerShell scripts for automation and system management
- Text-based documentation and procedural notes
- Utility files, templates, and other technical or operational assets

> ⚠️ **Note:** This is an actively used and evolving repository. File structure and contents may change as new needs arise.


## 🔧 Technologies

While the contents may vary, the primary technology used is:

- **PowerShell** – For automation, configuration, and system reporting tasks on Windows-based systems.
- **TextFiles** - Random files for documentation that I find important or worth tracking
